    - `SwipeRow.tsx` is the one swipe primitive. It uses pointer events and locks to an axis after 10 px, with a 1.2 horizontal bias. It commits past 35% of the row width, capped at 140 px. Crossing that threshold arms the action and fires a haptic tick. Short of it, the row springs back. It carries `data-swipe-ignore`, so the tab pager leaves the gesture alone. It swallows the click that ends a drag and blocks native link and image drags. Each action also has a real labelled button that only shows on keyboard focus, and a row can turn that off when it already shows its own control.

- Open: @capacitor/haptics is not a dependency, and adding it touches package.json and the Android project, which belong to S21. The code calls it by name and falls back to vibration, so until the plugin ships, Android gets at most the web vibration fallback (where the WebView allows it), not a native haptic. I recommend a small native slice that adds `@capacitor/haptics` and runs `cap sync`.
